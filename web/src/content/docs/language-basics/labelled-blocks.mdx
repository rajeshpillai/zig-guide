Label a block and `break` out of it with a value:

```zig
const count = blk: {
    var sum: u32 = 0;
    for (0..10) |i| sum += i;
    break :blk sum;
};
```

The name `blk` is arbitrary. What matters is that a multi-statement computation
still produces a single `const`, so the intermediate `var` cannot leak into the
surrounding scope or be accidentally reused later.

This is the Zig answer to "I need a few lines to compute this, but I want the
result to be immutable", a pattern that otherwise pushes people toward a
mutable variable with a wider scope than it deserves, or a single-use function.
