A loop can produce a value: `break x` yields `x`, and the `else` branch supplies
the value when the loop finishes without ever breaking.

```zig
return for (haystack, 0..) |c, i| {
    if (c == needle) break i;
} else null;
```

That is a complete linear search, and the "not found" case is structurally
impossible to forget: leave off the `else` and it does not compile.

Compare the usual alternative:

```zig
var result: ?usize = null;
for (haystack, 0..) |c, i| {
    if (c == needle) { result = i; break; }
}
return result;
```

Same behaviour, but now `result` is mutable, lives longer than it needs to, and
nothing forces you to initialise it correctly.
