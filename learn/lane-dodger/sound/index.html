Sound Without Sound Files

Updated 20 Oct 2026 · Code verified against Zig 0.18.0-dev.753+1420479be

This project has no audio files. The five effects are arithmetic. The game generates them when it starts.

To record or license five short sounds would take less time than to write a synthesiser. But that choice also adds three costs:

  • A folder of binary files that nobody can diff.
  • A licence question for each file.
  • An audio editor for each change.

When the game generates the sounds, a sound changes when a number changes.

One oscillator with an envelope

Each layer has a frequency sweep, an amplitude envelope, and an optional low pass. The low pass removes the high hiss from noise. delay starts a layer later than the others. The arpeggios use delay, thus they need no sequencer code.

The coin has two layers: a triangle, and a quieter sine one octave higher.

The crash has six layers. The last three layers are the descending triad that plays over the game over screen:

The six layers are one sound, and not two sounds. As two sounds, the thud would play at impact and the sting would play when the retry prompt appears. Then the code must record if the sting played yet, for a run that is already over. A layer can have a delay, thus the pause is in the waveform.

The renderer

The frequency sweep is exponential and not linear. Pitch is logarithmic. Thus a linear sweep sounds as if it becomes faster near the end.

The renderer adds the layers together, then soft clips the sum with tanh. It does not clamp the sum. Layers on top of each other go past the limit, and a clamp cuts the peaks flat. You hear the flat peaks as distortion.

The envelope, and the click

The envelope is exactly zero at the two ends of each layer.

If a clip starts at full amplitude, the clip starts with a step. The step goes from silence to the value of the waveform at that point. A step of this type is a broadband impulse. The speaker plays it as a click, and the click is usually louder than the effect. The same problem occurs at the end.

A fade in of four milliseconds is sufficient. The decay has a shape that stops at zero, and the code does not cut the decay at zero.

Test a waveform

The synthesiser contains no raylib types. It fills a buffer with samples and stops. Thus the tests check the sounds without an audio device. CI has no speakers.

The next test checks the mix. The exact frequencies are a matter of taste, and they can change. The relation between the sounds must not change. The crash is the low, long and loud sound. The lane tick plays on each input, and it must not be louder than a pickup.

Here, brightness is the number of zero crossings each second. This number is only an approximate estimate of pitch. But it is sufficient to tell a chime from a thud.

The measurements show that the five sounds are as intended. The coin is at approximately 1130 Hz for 85 ms. The crash lasts 900 ms, with 81 percent of its energy below 500 Hz. The lane tick is the shortest and the quietest sound. If you prefer to listen, zig build sounds writes all of the sounds as .wav files.

Play the sounds

If a sound already plays, raylib starts that sound again from the start. Thus one handle can make only one note at a time. During a combo, coins arrive quickly, one after the other. Each coin would stop the sound of the previous coin. An alias uses the same sample data as the sound, but each alias has its own playback position.

The combo ladder is a pitch multiplier on the one coin sound. It is not eight recordings:

Optional at runtime

The device does not open in these cases:

  • A machine with no sound card.
  • A container with no ALSA.
  • A browser tab that nobody clicked yet.

In each of these cases, each call above does nothing.

The sound in this game is decoration. Thus the game must start when a mixer does not open. To check this, the real binary runs with an ALSA configuration that has an error on purpose.

The sound reads the same event stream as the particles. The tests that were already there continued to pass during the work on the sound.
