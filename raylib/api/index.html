API reference

raylib-zig has 1001 functions. Each entry shows the Zig signature, the C one it wraps, raylib's description, and the examples that call it. The reference is generated from the same data as the Zig API, so it matches the code.

In Zig, a function keeps raylib's name with the first letter in lower case: DrawText isrl.drawText. raymath is rl.math, rlgl is rl.gl, and raygui is a module of its own, @import("raygui"), without the Gui prefix: GuiButton isgui.button.

raylib-zig is an unofficial port. It is not raylib.com and is not made by the raylib project.
