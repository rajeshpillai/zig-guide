About

raylib-zig is a port of raylib from C to Zig. It is an independent, unofficial project. It is not raylib.com, and the raylib project does not maintain it.

raylib

raylib is a library for making games and graphics programs. It is created by Ramon Santamaria (@raysan5) and many contributors. Its design is what this port keeps: the same functions, the same names, the same behaviour.

The examples

Every example on this site is one of raylib's own. The C source is shown unchanged, with its original author and license. The Zig version is a translation made for raylib-zig.

Licenses

raylib and its examples are licensed under the zlib/libpng license. raylib-zig keeps that license and the original copyright notices.
