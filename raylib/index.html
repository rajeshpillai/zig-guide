raylib, ported to Zig

raylib-zig is raylib 6.2 rewritten in Zig. It exports the same C API, so a C program written for raylib links against it unchanged. On top of that it has a Zig API in raylib's own style.

For every upstream example that can run deterministically, the Zig library renders a final frame byte-identical to C raylib (217 of 217, on Linux, desktop GLFW, OpenGL 3.3). In the browser, 209 examples are checked the same way so far. How that is checked.

raylib-zig is an unofficial port. It is not raylib.com and is not made by the raylib project.

raylib is created by Ramon Santamaria (@raysan5) and contributors, under the zlib/libpng license. The examples keep their original license and authors.
